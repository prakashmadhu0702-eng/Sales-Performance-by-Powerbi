# Sales-Performance-by-Powerbi

Project Overview

This project analyzes sales data to understand business performance, identify top-performing products, and track regional sales trends. An interactive Power BI dashboard was created to visualize key sales metrics and provide insights that support data-driven decision making.

Objectives
   
 1)  Analyze overall sales performance and revenue trends
   
 2) Identify top-performing products and categories
   
 3)  Evaluate regional sales distribution
   
 4) Monitor key business metrics using KPIs
   
 5)  Build an interactive Power BI dashboard for business insights

Tech Stack
  
 1)  Power BI
   
 2) Power Query
   
 3)  DAX
   
 4) Excel / CSV Dataset
   
Key KPIs

 1) Total Sales
  
 2) Total Profit
  
 3) Total Orders
  
 4) Average Sales

Top Performing Products

   1) Sales by Region
   
   2) Monthly Sales Trend
   
Dashboard Features

   1)Interactive filters and slicers
   
   2)Sales trend analysis
   
   3)Regional performance comparison
