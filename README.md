# Sales-Performance-by-Powerbi

Project Overview

This project analyzes sales data to understand business performance, identify top-performing products, and track regional sales trends. An interactive Power BI dashboard was created to visualize key sales metrics and provide insights that support data-driven decision making.

Objectives
   
   #Analyze overall sales performance and revenue trends
   
   #Identify top-performing products and categories
   
   #Evaluate regional sales distribution
   
   #Monitor key business metrics using KPIs
   
   #Build an interactive Power BI dashboard for business insights

Tech Stack
  
   Power BI
   
   Power Query
   
   DAX
   
   Excel / CSV Dataset
   
Key KPIs

  Total Sales
  
  Total Profit
  
  Total Orders
  
  Average Sales

Top Performing Products

   Sales by Region
   
   Monthly Sales Trend
   
Dashboard Features

   Interactive filters and slicers
   
   Sales trend analysis
   
   Regional performance comparison
